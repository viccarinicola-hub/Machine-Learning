# Machine-Learning

## Description
This project analyzes EV market share using Random Forest and segments markets with K-Means and PCA. Key drivers are emission regulations and vehicle type; infrastructure and fuel prices also impact adoption. Markets cluster as Leaders, In Transition, and Emerging, with GDP per capita as an entry barrier but not the main driver.
